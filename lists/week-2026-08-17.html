This week was less about AI coding and more about everyday stuff: videos, mice and free data. Here's what each repo does and how to try it.

Key takeaways

1. MoneyPrinterTurbo: a short video from one topic

Stars: +11.0K this week · about 131.5K total

What it is: Type a topic or a keyword. MoneyPrinterTurbo writes the script, finds matching video clips, adds a voiceover, subtitles and music, and exports an HD video. It can make tall 9:16 videos for Reels and TikTok, or wide and square ones. A free voice option needs no key.

Who it's for: Creators, shop owners and anyone who needs lots of short videos.

Everyday use: "5 tips for better sleep" in, a vertical video with voice and subtitles out.

Install it: On Windows, the README's easiest path is the one-click package on the Releases page. With Docker (a free app that runs software in a sealed box), copy and paste this:

git clone https://github.com/harry0703/MoneyPrinterTurbo.git
cd MoneyPrinterTurbo
docker compose -f docker-compose.release.yml up

Then open http://127.0.0.1:8501 in your browser.

Let Claude or Codex do it:

Install MoneyPrinterTurbo from github.com/harry0703/MoneyPrinterTurbo, help me add my AI and Pexels keys, and make a 30-second vertical test video.

⚠️ Heads up: Despite the name, it prints videos, not money. The script writer uses an AI model, which usually needs a paid key. Free stock footage sites like Pexels ask for a free key too.

2. public-apis: a giant menu of free data

Stars: +9.4K this week · about 489K total

What it is: A long list of free APIs, sorted by topic. An API is a doorway that lets one app ask another for data. Think weather, recipes, sports scores or dog photos.

Who it's for: People learning to code, and anyone building a small app with AI help.

Everyday use: Find a free weather API, then ask your AI helper to build a tiny "should I bike today?" page with it.

Install it: Nothing to install. Browse it on GitHub. Want a local copy? Copy and paste this:

git clone https://github.com/public-apis/public-apis.git

Let Claude or Codex do it:

Pick a free weather API from github.com/public-apis/public-apis and build me a one-page site that shows today's forecast for my city.

See public-apis on GitHub

3. OpenLogi: your Logitech mouse, your rules

Stars: +5.0K this week · about 23.6K total

What it is: A free app that replaces Logitech Options+. It remaps buttons and changes pointer speed and scroll-wheel behavior. It needs no account and sends no usage data.

Who it's for: Anyone with a Logitech mouse who's tired of logins and heavy software.

Everyday use: Set the side button to "copy" and the other to "paste."

Install it: Download it from the Releases page (Mac, Windows or Linux). On a Mac with Homebrew, copy and paste this:

brew install --cask openlogi

Quit Logi Options+ first. The two apps fight over the same connection.

4. OpenViking: a filing cabinet for AI memory

Stars: +3.4K this week · about 40.0K total

What it is: A "context database" from Volcano Engine. It stores what an AI agent knows, remembers and can do as folders and files. So you can open it and see what's stored, instead of guessing.

Who it's for: People building AI agents that need to remember users and projects.

Everyday use: Check exactly what your agent "remembers" about you, and edit it like a note.

Install it: You can try OpenViking Studio in your browser first. To run it yourself, copy and paste this:

uv tool install openviking --upgrade && openviking-server init

Let Claude or Codex do it:

See OpenViking on GitHub

5. Cordis: build apps from swappable parts

Stars: +3.4K this week · about 9.2K total

What it is: A framework, which is a starter kit for programmers. Cordis lets you build an app from plug-in parts you can add, swap or remove while it runs. The README warns it is under active development, and its API may change.

Who it's for: Programmers only. If you don't code, skip this one.

Everyday use: Build a chat bot where each feature is a plug-in you can switch on and off.

Install it: Copy and paste this:

npm install cordis

Let Claude or Codex do it:

See Cordis on GitHub

Which one should you try first?

  • You post short videos: go for MoneyPrinterTurbo.
  • You own a Logitech mouse: install OpenLogi today. It's the quickest win.
  • You're learning to code: bookmark public-apis.
  • You build AI agents: test OpenViking, then peek at Cordis.

💡 Tip: Brand new to all this? OpenLogi is a normal app you download and click. No terminal needed.

FAQ

What were the top GitHub repos Aug 17 2026?

MoneyPrinterTurbo (+11.0K stars), public-apis (+9.4K), OpenLogi (+5.0K), OpenViking (+3.4K) and Cordis (+3.4K).

Is MoneyPrinterTurbo free?

The software is free and open source. The AI model that writes scripts usually needs a paid key, and some voice and video services cost money too.

Does OpenLogi work without Logitech's app?

Yes. That's the point. Quit Logi Options+ first, because only one app can control a receiver at a time.

What is an API?

It's a doorway that lets one program ask another for data, like today's weather. public-apis lists free ones.
