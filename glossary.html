A

  • A2AA2A, or Agent2Agent, is an open standard that lets AI agents from different makers talk to each other and share work.Agents & tools
  • AcquisitionAn acquisition is when one company buys another company, or most of it.Business & money
  • Agent skillsAgent skills are small packs of instructions and files that teach an AI agent how to do one kind of task well.Agents & tools
  • Agentic AIAgentic AI is AI that acts on its own to reach a goal, making plans and taking steps instead of only answering questions.Agents & tools
  • AGIAGI, or artificial general intelligence, is a future AI that could learn and do most thinking tasks as well as a person.Models
  • AGPLThe AGPL is a strict open-source license like the GPL, but it also covers software people use over a network.GitHub & code
  • AI agentAn AI agent is an AI that can plan steps and use tools on its own to finish a goal you give it.Agents & tools
  • AI alignmentAI alignment is the work of making an AI system do what people actually want and follow human values.Safety & law
  • AI avatarAn AI avatar is a digital character or person on screen that speaks and moves using AI.Media & creative
  • AI bubbleThe AI bubble is the worry that prices and spending on AI have grown much faster than the real money AI earns.Business & money
  • AI chipAn AI chip is a computer chip built to run AI math fast, such as a GPU, a TPU or an NPU.Hardware
  • AI coding agentAn AI coding agent is a tool that can read your code, write changes, run commands and fix errors with little help.Agents & tools
  • AI memoryAI memory is a way for an AI to keep facts about you or your work so it can use them in later chats.Agents & tools
  • AI modelAn AI model is a computer program that learned patterns from examples and uses them to make predictions or create things.Models
  • AI music generationAI music generation is technology that creates songs, tunes or sound from a written description.Media & creative
  • AI PCAn AI PC is a laptop or desktop with a built-in chip for AI tasks, so it can run some AI features on the device.Hardware
  • AI regulationAI regulation means the laws and rules that governments make about how AI can be built and used.Safety & law
  • AI safetyAI safety is the work of making sure AI systems are reliable and don't cause harm, whether by mistake or by misuse.Safety & law
  • AI upscalingAI upscaling is using AI to make a small or blurry image or video larger and sharper.Media & creative
  • AI watermarkAn AI watermark is a hidden or visible mark added to AI-made content so it can be recognized as AI-generated.Safety & law
  • Apache 2.0Apache 2.0 is a popular open-source license that allows broad use and includes a clear patent permission.GitHub & code
  • APIAn API is a set of rules that lets one piece of software ask another piece of software to do something.Building with AI
  • API keyAn API key is a secret code that proves to a service that a request comes from you.Building with AI
  • API pricingAPI pricing is how AI companies charge developers for using their models, usually by the amount of text sent and received.Business & money
  • Apple SiliconApple Silicon is the family of chips Apple designs for its Mac, iPhone and iPad, with the processor and graphics on one chip.Hardware
  • ARC-AGIARC-AGI is a set of visual puzzles that tests whether an AI can learn a new pattern from just a few examples.Benchmarks
  • ARRARR is the yearly money a company expects from its regular customers, based on what they pay now.Business & money

B

  • Background removalBackground removal is AI that cuts the main subject out of a photo and removes everything behind it.Media & creative
  • BenchmarkA benchmark is a standard test that lets you compare how well different AI models do the same tasks.Benchmarks
  • Benchmark contaminationBenchmark contamination is when an AI has already seen a test's questions or answers, so its score looks better than its real skill.Benchmarks
  • Browser agentA browser agent is an AI that uses a web browser for you, clicking links, filling forms and reading pages like a person would.Agents & tools

  • Chain of thoughtChain of thought is when an AI writes out its steps one by one before it gives a final answer.Models
  • ChatbotA chatbot is a program you talk to in everyday language, by typing or speaking, and it replies like a person would.Agents & tools
  • ChatGPTChatGPT is an AI chatbot from OpenAI that answers questions, writes text and helps with tasks in plain language.Agents & tools
  • ClaudeClaude is a family of AI models and a chatbot made by the company Anthropic.Agents & tools
  • Claude CodeClaude Code is a coding tool from Anthropic that lets the Claude AI read your code, edit files and run commands for you.Agents & tools
  • CLIA CLI is a way to control a program by typing short text commands instead of clicking buttons.GitHub & code
  • Closed modelA closed model is an AI model whose files are kept private, so you can only use it through the maker's app or service.Models
  • Cloud computingCloud computing means using computers owned by someone else, over the internet, instead of your own.Building with AI
  • CodexCodex is a coding agent from OpenAI that can read your code, make changes and run tasks for you.Agents & tools
  • CommitA commit is a saved snapshot of your changes in Git, with a short note about what you changed.GitHub & code
  • ComputeCompute is the computing power used to train and run AI, mostly made up of chips, time and electricity.Hardware
  • Computer useComputer use is when an AI looks at a screen and clicks, types and scrolls like a person to do tasks on a computer.Agents & tools
  • Computer visionComputer vision is AI that lets computers understand what is in pictures and videos.Media & creative
  • ContainerA container is a small, sealed package that holds an app and everything it needs to run.GitHub & code
  • Content CredentialsContent Credentials are a digital label attached to a file that shows who made it and whether AI was used.Media & creative
  • Context engineeringContext engineering is choosing what information an AI sees, such as instructions, files and past messages, so it can do its job well.Building with AI
  • Context windowA context window is the amount of text an AI model can keep in mind at one time while it answers.Models
  • CopyrightCopyright is the legal right of a creator to control who can copy, share or sell their original work.Safety & law
  • CPUA CPU is the main chip in a computer, the part that follows instructions and runs your programs one step after another.Hardware
  • CUDACUDA is software from NVIDIA that lets programs use NVIDIA graphics cards for fast math, and many AI tools depend on it.Hardware
  • CursorCursor is a code editor with AI built in, so you can ask it to write, change or explain code.Agents & tools

D

  • Data centerA data center is a big building full of computers that store data and run online services, including AI models.Hardware
  • Deep learningDeep learning is a kind of machine learning that uses neural networks with many layers to learn complex patterns.Models
  • DeepfakeA deepfake is a fake photo, video or voice made by AI that looks or sounds like a real person.Safety & law
  • DependencyA dependency is another piece of software that a program needs to work.GitHub & code
  • Diffusion modelA diffusion model is an AI that makes images by starting from random noise and cleaning it up step by step.Models
  • DistillationDistillation is a way to teach a small AI model to copy the answers of a bigger one.Models
  • DockerDocker is a free tool that packs an app and everything it needs into one box so it runs the same anywhere.GitHub & code

E

  • Edge AIEdge AI is AI that runs on your own device, like a phone or camera, instead of on a faraway server.Hardware
  • Elo ratingAn Elo rating is a score that goes up when you win and down when you lose, based on who you beat.Benchmarks
  • EmbeddingsEmbeddings are lists of numbers that stand for the meaning of text, images or other data so a computer can compare them.Models
  • EncryptionEncryption scrambles information so only someone with the right key can read it.Safety & law
  • Environment variableAn environment variable is a named setting stored outside your code, often used to hold things like API keys.Building with AI
  • EU AI ActThe EU AI Act is a European Union law that sets rules for AI, with stricter rules for uses that carry more risk.Safety & law

  • Fair useFair use is a rule in United States law that lets people use parts of copyrighted work in some cases without asking.Safety & law
  • Fake GitHub starsFake GitHub stars are stars bought or faked to make a project look more popular than it really is.Safety & law
  • Fine-tuningFine-tuning is giving an already trained AI model extra practice on specific examples so it gets better at one job.Models
  • FLOPsFLOPs count the math steps a computer does, and AI people use them to measure how much work a model needs.Hardware

  • Foundation modelA foundation model is a large AI model trained on broad data that can be adapted to many different jobs.Models
  • FreemiumFreemium is a pricing style where a basic version is free and extra features cost money.Business & money
  • Frontier modelA frontier model is one of the most capable AI models available at a given time, made by a top AI lab.Models
  • Funding roundA funding round is a moment when a company sells shares to investors to raise money.Business & money

  • GDPRGDPR is a European Union privacy law that gives people control over their personal data and sets rules for companies.Safety & law
  • GeminiGemini is Google's family of AI models and the chatbot that uses them.Agents & tools

  • GPUA GPU is a computer chip built to do many small calculations at the same time, which makes it great for graphics and AI.Hardware
  • GuardrailsGuardrails are rules and checks that keep an AI system from giving harmful, off-topic or unsafe answers.Safety & law

  • HallucinationA hallucination is when an AI states something false or made up in a confident way.Models
  • HBMHBM is a very fast type of memory stacked in layers and placed right next to an AI chip.Hardware
  • Headless browserA headless browser is a web browser that runs without a visible window, so programs can load and control web pages automatically.Agents & tools
  • HomebrewHomebrew is a free tool for Mac and Linux that installs software using one short command.GitHub & code

  • InferenceInference is when a trained AI model is used to answer a question or make something, as opposed to learning.Models
  • InpaintingInpainting is AI that fills in or replaces part of an image, based on the area around it and your instructions.Media & creative
  • IPOAn IPO is when a private company sells its shares to the public for the first time.Business & money

  • Machine learningMachine learning is a way of building software that learns from examples instead of following rules written by hand.Models

  • NPUAn NPU is a small chip inside a phone or laptop that is built to run AI tasks quickly while using little battery.Hardware

  • OCROCR is technology that reads text in pictures or scans and turns it into text you can edit and search.Media & creative
  • OllamaOllama is a free tool that lets you download and run AI models on your own computer.Agents & tools
  • Open sourceOpen source means software whose code is public, so anyone can read it, use it, and often change it.GitHub & code
  • Open weightsOpen weights means a company shares an AI model's trained files so anyone can download and run the model.Models
  • OpenRouterOpenRouter is a service that gives you one account and one API key to use many different AI models.Agents & tools

  • Package managerA package manager is a tool that finds, installs, updates and removes software add-ons for you, so you don't do it by hand.GitHub & code

  • Pay as you goPay as you go means you pay only for what you use, instead of a fixed monthly fee.Business & money

  • PythonPython is a popular, beginner-friendly programming language, widely used for AI tools.GitHub & code
