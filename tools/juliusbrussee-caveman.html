Caveman: make your AI coding helper talk less and cost less

A free add-on that makes AI coding assistants give short, caveman-style answers and read less, so you spend fewer tokens.

Developers

stars: 112K · license: Apache-2.0 · platforms: Works with 30+ AI coding agents

The problem it solves

Ask an AI coding assistant a simple question and you may get a whole essay back. "The reason your component is re-rendering is likely because..." and on it goes. The fix you needed was one line.

That chatter is not free. AI tools charge by "tokens" (small chunks of text the AI reads or writes). Every extra word costs a bit of money and time. It also fills up the AI's short-term memory faster.

Caveman cuts the chatter. Its motto says it all: "why many token when few do trick."

What it is

Caveman is a free add-on for AI coding assistants like Claude Code, Codex, Gemini CLI and OpenCode. It started as a joke in April 2026 and grew into a serious tool.

At its heart, it gives your AI a new way of talking: answer first, short sentences, no greetings, no recap. Code, commands and error messages stay exactly the same, character for character. Only the extra words go.

The README shows one example. A normal answer took 63 tokens. The caveman answer gave the same fix in 20.

Since version 4.0, Caveman is more than a voice. It has six parts, all switched on after install, and each can be turned off on its own.

Who it's for

  • Developers who use AI coding assistants all day.
  • People paying per token who want smaller bills.
  • Teams who find long AI answers slow to read.

This is a tool for people who code with AI in a terminal. If you do not use a coding assistant, it will not help you much.

What you can do with it

From the README, the six parts are:

  • Say less: short, clear answers. Words like "not," "never" and "only" are always kept, and numbers stay exact. For security warnings or risky actions, it switches back to full sentences.
  • Read less: shrinks logs, data files and test results before the AI reads them. The README reports 33.2% fewer input tokens across its test sessions, with the same answers.
  • Auto: picks which AI model and how much effort to use for each question. Hard question, big model. Easy question, cheaper one. This part needs a free account.
  • Blocks: saves small scripts the AI writes so it can reuse them instead of rewriting them every time. This part is still a pre-release.
  • Waste fixes: shows where your tokens go and suggests fixes, only applying them when you say yes.
  • Browse: sends web pages to the AI in a much smaller form.

You can also pick how short it gets: /caveman, the shorter /ultracave, or /megacave, which uses classical Chinese.

How to start, step by step

What you need first: Node.js version 22.13 or newer (a free program you can get from nodejs.org), and an AI coding tool such as Claude Code.

  1. Open Terminal and paste:
npx @caveman-ai/cli@latest
  1. Caveman finds your AI tools and shows what it will change.
  2. Press Enter to accept.
  3. Use your AI tool as normal. Answers should now come back short.
  4. Type caveman status to see which parts are on. Say "stop caveman" in a chat to go back to normal answers.

Only want shorter answers? Install just the voice instead:

npx skills add JuliusBrussee/caveman -g

Good to know

  • Savings vary. The README is honest about this. It shows where Caveman loses, like web pages saved as HTML, which have no shrinker yet. Your results will depend on your work.
  • "Be concise" already helps. The README admits newer AI models already shorten answers when asked. Caveman's extra savings on top of that were small for the standard mode and bigger for /ultracave.
  • Not always cheaper. If your plan charges per request rather than per token (like GitHub Copilot), shorter answers save nothing.
  • Privacy: the voice add-on sends nothing. The full command-line tool sends usage stats by default, but never your prompts, code or file paths. Turn it off with caveman telemetry off. The Auto feature sends parts of your conversation to Caveman's cloud, and only after you sign in and choose it.
  • Cost: the tool is free. Your AI provider still bills you as usual. A separate Caveman Cloud service exists for teams building their own AI agents.
  • License (Apache-2.0): free to use, change and even use in a business. Keep the license notice. The "Caveman" name and rock logo are trademarks of the author.

The bottom line

Caveman makes your AI coding assistant get to the point and read less noise. It installs with one command, keeps code exact, and is open about where it helps and where it does not. If long AI replies are eating your time or budget, it is an easy thing to try.
