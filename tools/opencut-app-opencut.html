OpenCut: the free, open-source CapCut alternative

A free, open-source video editor that runs in your browser, now being rebuilt for desktop, mobile and AI agents.

CreatorsMediaMarketing

stars: 94K · license: MIT · platforms: Web browser (desktop and mobile apps in progress)

The problem it solves

Simple video editing should not cost a monthly fee. Yet many popular editors lock handy features behind subscriptions, or change their rules and prices with little warning. If you just want to trim clips for a social post, a school project or a product demo, that gets old fast.

People also worry about who owns their editor and their data. When an app is closed and controlled by one company, you have no say.

What it is

OpenCut is a free and open-source video editor for the web, desktop and mobile. It was built as an alternative to CapCut. "Open source" means the code is public, so anyone can check it, improve it, or run their own copy.

There are two versions right now, and it helps to know which is which:

  • The classic version runs today at opencut.app in your web browser. This is the one to use now.
  • A full rewrite is in progress. The team is rebuilding OpenCut from the ground up. While it is being built, it lives at new.opencut.app.

Who it's for

  • Social media creators who want to cut clips without a paid plan.
  • Small business owners and marketers making quick promo or product videos.
  • Students and teachers editing class projects and lesson videos.
  • Community groups and nonprofits on a tight budget.
  • Developers who want an editor they can extend or automate later.

What you can do with it

Today, with the classic version:

  • Edit video in your browser at opencut.app, with nothing to install.
  • Use it for free, with no subscription.
  • Trust open code that anyone can read, under a permissive license.

Coming in the rewrite, according to the README:

  • One editor for desktop, mobile and browser, all from the same core code.
  • Third-party plugins (add-ons made by other people), built in from the start.
  • An Editor API, so other programs can control the editor.
  • An MCP server, a standard way for AI agents to use the editor for you.
  • Headless mode, for automation and batch rendering without opening the editor.
  • A scripting tab right inside the editor.

How to start, step by step

First you need: a computer with a modern web browser. That is it for the classic version.

  1. Open opencut.app in your browser.
  2. Create a new project.
  3. Drag in your video clips.
  4. Start cutting and editing.

Curious about the future version? Visit new.opencut.app to see the rewrite as it grows. Keep in mind it is unfinished.

For developers only: the README explains how to run the new code yourself. You install a tool manager called proto, run proto use in the project folder, then start the web app with moon run web:dev. Most people can skip this and just use the website.

Good to know

  • The rewrite is not ready yet. The README says the classic version is "the one to reach for today." Expect the new version to change a lot.
  • Classic code lives elsewhere. The older code is in a separate project called opencut-classic on GitHub.
  • Outside help is paused. The team is not taking outside code contributions while it designs the new structure. You can still join their Discord or open an issue to ask questions.
  • Free to use. No price is listed for the editor. It is supported by sponsors.
  • Desktop and mobile apps are in progress, not released yet.
  • License. It uses MIT. In plain words: free to use, change and share, even for paid work, as long as you keep the copyright notice.

The bottom line

OpenCut is a free, open video editor you can use in your browser today, with no subscription. A bigger rebuild is on the way with plugins, desktop and mobile apps, and AI agent support. If you are tired of paying monthly just to trim clips, give the classic version a try now and keep an eye on the new one.
