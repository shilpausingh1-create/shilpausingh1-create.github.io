gstack: use Y Combinator's CEO's own AI coding setup for free

Garry Tan's free Claude Code skills that act like a virtual CEO, designer, code reviewer, QA tester and release engineer.

DevelopersBusiness

stars: 136K · license: MIT · platforms: Works inside Claude Code

The problem it solves

An AI coding helper with a blank prompt is powerful but aimless. It builds exactly what you typed, even if what you typed is not what you need. It rarely pushes back. It does not ask, "Is this the right product?" And it often skips the boring parts: reviews, testing and careful releases.

Real companies have people for each of those jobs. A solo founder usually does not.

What it is

gstack is a free, open-source set of tools for Claude Code (Anthropic's AI coding helper). It was made by Garry Tan, President and CEO of Y Combinator, a famous startup program.

It turns Claude Code into a virtual team. Each tool is a slash command (a shortcut you type starting with "/") that plays a role: a CEO who rethinks the product, an engineering manager who locks the plan, a designer who catches sloppy AI design, a reviewer who hunts bugs, a QA lead who tests in a real browser, a security officer, and a release engineer. The README counts twenty-three specialists and eight power tools.

The tools run in the order of a work sprint: think, plan, build, review, test, ship, reflect. Each step passes notes to the next.

Who it's for

The README names three groups:

  • Founders and CEOs, especially technical ones who still want to ship.
  • First-time Claude Code users who want clear roles instead of a blank prompt.
  • Tech leads and senior engineers who want careful review, testing and releases on every change.

It also fits product managers and designers who build with AI and want a second opinion before code is written.

What you can do with it

  • Get "office hours." /office-hours asks six tough questions about your idea, challenges your thinking, and writes a design doc.
  • Rethink the plan like a CEO. /plan-ceo-review looks for the better product hiding in your request.
  • Lock the technical plan. /plan-eng-review maps data flow, edge cases and tests.
  • Review the design. /plan-design-review rates each design choice from 0 to 10 and explains how to improve it.
  • Explore design options. /design-shotgun makes several AI mockups and lets you pick favorites.
  • Find bugs before launch. /review looks for problems that pass basic checks but break later, and fixes the obvious ones.
  • Test like a QA lead. /qa opens a real browser, clicks through your app, and fixes what it finds.
  • Run a security check. /cso audits for common security risks.
  • Ship it. /ship runs tests and opens a pull request (a proposed change for review). /land-and-deploy takes it live.
  • Stay safe. /careful warns before destructive commands. /freeze limits edits to one folder.
  • Reflect. /retro gives a weekly look back at what shipped.
  • Make documents. /make-pdf turns notes into polished PDFs, and /diagram turns plain English into diagrams.

How to start, step by step

What you need first: Claude Code, Git (a free tool for tracking code changes), and Bun (a free tool that runs code). Windows users also need Node.js. Windows works through Git Bash or WSL.

  1. Install the tools above if you do not have them.
  2. Open Claude Code and paste the install line from the README. Claude does the rest. The core command it runs is:
git clone --single-branch --depth 1 https://github.com/garrytan/gstack.git ~/.claude/skills/gstack && cd ~/.claude/skills/gstack && ./setup

The README's full paste also tells Claude to note the gstack skills in your settings file. The README says setup takes about 30 seconds on a fast machine, and longer on slower ones.

  1. Run /office-hours and describe what you are building.
  2. Try /plan-ceo-review on a feature idea.
  3. Run /review on code you changed, then /qa on your test website.

The README's advice: stop there. You will know if it is for you.

Good to know

  • Free, no premium tier. The README says there is no paid version and no waitlist.
  • AI costs are separate. You need Claude Code, which may have its own fees. Some features send code to a second AI (OpenAI's Codex) for an outside review using your own login. You can turn that off.
  • Telemetry is off unless you say yes. It asks once on first run. It never sends your code, file names or prompts.
  • It checks for updates. It asks GitHub for the latest version. You can turn that off too.
  • Best on Claude Code. Other AI tools are supported, but most are marked experimental.
  • Some extras need more setup. For example, some design tools use an OpenAI key.
  • License: MIT. Free to use, change and even use in business. Just keep the copyright notice.

The bottom line

gstack gives a solo builder the habits of a full product team: question the idea, plan it, review it, test it, ship it. It is free and installs in minutes inside Claude Code. Start with /office-hours and see how hard it pushes back.

Get it: github.com/garrytan/gstack
