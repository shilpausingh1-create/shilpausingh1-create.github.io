Why these picks

These free tools help you make campaigns, pages and content faster. There is an open-source SEO tool for keyword research, rank tracking and site audits, AI skills that make landing pages look on-brand instead of generic, and an AI design tool for prototypes, slide decks and images. For video, there is a browser editor with no watermark, a screen recorder for product demos, an AI video maker and a tool that turns a project into a short launch video. Each guide lists the price and the license, the setup steps from the tool's own page, and real examples you can try the same day.

All 12 tools here are open source on GitHub. By license: MIT (6), AGPL-3.0 (3), Apache-2.0 (2), MIT or Apache-2.0 (1). A tool can be free while an AI service it connects to is not, so check the price row in each guide's at-a-glance table.

Awesome DESIGN.md, with 121.5K stars when our guide last checked (2026-10-16).

Do they work on Mac, Windows and Linux?

5 of the 12 guides that list platforms say Mac, Windows and Linux. Each guide's at-a-glance table names the platforms for that tool.
