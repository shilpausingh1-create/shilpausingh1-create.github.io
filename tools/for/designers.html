Why these picks

These free tools are for people who make things look good: websites, slides, diagrams, photos and brand pages. Some are full apps, like a free Figma alternative that opens .fig files and two Photoshop-style editors that open PSD files. Others are skills and style files that steer an AI helper such as Claude Code, so the pages and diagrams it makes look on-brand instead of generic. Some of them run inside an AI coding helper, and every guide walks you through the setup step by step. Each guide also lists the license and the price, so you know what you are getting before you install anything.

FAQ

Are these AI tools for designers free?

All 8 tools here are open source on GitHub. By license: MIT (5), MIT or Apache-2.0 (2), Apache-2.0 (1). A tool can be free while an AI service it connects to is not, so check the price row in each guide's at-a-glance table.

Which of these tools has the most GitHub stars?

Awesome DESIGN.md, with 121.5K stars when our guide last checked (2026-10-16).

Do they work on Mac, Windows and Linux?

3 of the 8 guides that list platforms say Mac, Windows and Linux. Each guide's at-a-glance table names the platforms for that tool.
