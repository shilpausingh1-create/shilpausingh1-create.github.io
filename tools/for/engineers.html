Why these picks

These are free tools for people who write code, or who build apps with an AI coding helper like Claude Code or Codex. Many of them are add-ons that change how your AI helper works: they make it plan before it codes, test its own work, remember your project, or read fewer tokens so each session costs less. Others are full tools, like a database client, a light headless browser for AI agents, or a way to run Linux containers on a Mac. Every guide shows the install steps from the tool's own README, a ready prompt you can paste into your AI helper, and our honest pros and cons. Start with the one that fixes the problem you hit most this week.

Are these AI tools for engineers and developers free?

All 29 tools here are open source on GitHub. By license: MIT (18), Apache-2.0 (9), Apache-2.0 / MIT (1), Apache-2.0 + BUSL-1.1 (1). A tool can be free while an AI service it connects to is not, so check the price row in each guide's at-a-glance table.

Which of these tools has the most GitHub stars?

REA, with 317.7K stars when our guide last checked (2026-10-18).

Do they work on Mac, Windows and Linux?

15 of the 29 guides that list platforms say Mac, Windows and Linux. Each guide's at-a-glance table names the platforms for that tool.
