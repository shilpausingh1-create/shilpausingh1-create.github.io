World Monitor: all the world's news on one free live map

A free live dashboard that puts global news, markets and events on one interactive map, with short AI-written news briefs.

EveryoneFinanceMedia

stars: 88K · license: AGPL-3.0 · platforms: Web, Mac, Windows, Linux

The problem it solves

Following world news is tiring. You open one tab for headlines, another for stock prices, another for weather disasters, and another for a map so you know where things are. Soon you have twenty tabs open and still miss the big picture.

It is even harder if your job depends on it. A trader wants to know when a crisis may move oil prices. A reporter wants to see which stories are linked. A teacher wants a simple way to show a class what is happening around the globe today.

What it is

World Monitor is a free, open-source "global intelligence dashboard." That is a fancy name for one screen that pulls together news, markets and events from around the world and shows them on a live map.

It gathers curated news feeds from global and regional sources. Then AI turns those feeds into short briefs, so you can read the gist fast. You can view everything on a 3D globe you can spin, or on a flat map.

It comes in a few flavors, all built from the same code: the main world view, plus tech, finance, commodity, energy and "happy" versions. You can use it in your web browser or download a desktop app.

Who it's for

  • News lovers who want one place to see what is happening and where.
  • Investors and finance workers who want markets and world events side by side.
  • Journalists and researchers who track conflicts, disasters and how events connect.
  • Teachers and students who want a visual way to explore current events.
  • Energy and commodity watchers who follow oil, gas and raw materials.
  • Developers who want world data inside their own apps or AI agents.

What you can do with it

  • Read AI news briefs. Curated feeds from many regions are summed up into short briefs.
  • Spin a 3D globe or switch to a flat map, with layers you can turn on and off.
  • Spot linked events. It looks for places where military, economic, disaster and escalation signals come together.
  • Check country risk scores. A "Country Instability Index" gives live scores and rough 24-hour movement for 31 key countries.
  • Watch the finance radar. Stock exchanges, commodities, crypto and an overall market score.
  • Switch views. Tech, finance, commodity, energy and happy versions, inside one desktop app.
  • Use your own language. The screen supports many languages, with local-language feeds and right-to-left text.
  • Run AI on your own computer. It can use Ollama (a free tool for running AI locally), so no AI account keys are needed.
  • Connect it to other tools. It offers an API (a way for apps to talk to each other), a command-line tool, and kits for Python, Ruby and Go.

How to start, step by step

The easiest path needs nothing but a web browser.

  1. Open the website. Go to worldmonitor.app. For a focused view, try finance.worldmonitor.app, tech.worldmonitor.app, energy.worldmonitor.app, commodity.worldmonitor.app or happy.worldmonitor.app.
  2. Explore the map. Spin the globe, zoom in, and turn on the news layers you care about.
  3. Read the briefs. Open the AI briefs for a quick summary, or check the finance radar.

Want a desktop app instead? The README links downloads for Windows (.exe), Mac (Apple chips and Intel) and Linux (.AppImage). One app covers every version, and you switch views inside it.

If you are technical and want to run your own copy, you need Git and Node.js (a free tool many apps need). Then run:

git clone https://github.com/koala73/worldmonitor.git
cd worldmonitor
npm install
npm run dev

Then open localhost:3000 in your browser. The README says it runs with no extra settings, though some data sources need their own keys.

Good to know

  • Free to use. The public website and the desktop app are free.
  • Some extras need a key. Using the API or command-line tool for some requests needs an API key from worldmonitor.app/pro. The README does not list prices, so check that page.
  • AI briefs are summaries. They are written by AI from news feeds. For big decisions, read the original sources too.
  • Local AI option. If you care about privacy, you can run the AI part on your own machine with Ollama.
  • License: AGPL-3.0. You are free to use it and change it. But if you share a changed version, you must share its code too. That also applies if you run your changed version as an online service for others. Using the official branding needs separate permission.

The bottom line

World Monitor turns a messy pile of news tabs into one live map with short AI summaries. It is free in your browser, has a desktop app, and works for anyone from curious readers to finance pros. Open the website and spin the globe to see if it fits your day.

Get it: github.com/koala73/worldmonitor
