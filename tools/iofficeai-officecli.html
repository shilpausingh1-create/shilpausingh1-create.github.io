OfficeCLI: let your AI build real Word, Excel and PowerPoint files

OfficeCLI is a free tool that lets AI helpers create, read and edit real Word, Excel and PowerPoint files, no Office install needed.

BusinessStudentsEveryone

stars: 32K · license: Apache-2.0 · platforms: Mac, Windows, Linux

The problem it solves

You ask an AI chatbot for a slide deck. It gives you a wall of text. Then you spend an hour copying it into PowerPoint, fixing fonts, and moving boxes around.

The same thing happens with reports and spreadsheets. The AI knows what to say. It just cannot touch the actual file. So the boring part, the formatting, still lands on you.

OfficeCLI was built to close that gap. It gives AI helpers a way to make and change real Office files on their own.

What it is

OfficeCLI is a free, open-source tool. Open source means anyone can read the code that runs it. It works with the three file types most offices live in: Word documents (.docx), Excel spreadsheets (.xlsx) and PowerPoint decks (.pptx).

It can create these files, read them, and edit them. You do not need Microsoft Office installed. It comes as a single program file with no extra pieces to set up.

The clever part is what the makers call giving AI "eyes." OfficeCLI can turn a document into a web page or a picture. That lets the AI look at what it made, spot problems like a title that spills off the slide, and fix them. The README calls this the "render, look, fix" loop.

It is a command-line tool, which means it runs from a text window instead of buttons. But most people will never type its commands. Your AI helper does that for you.

Who it's for

  • Office workers who build the same weekly report or deck again and again.
  • Teachers making handouts, gradebooks, or lesson slides.
  • Students putting together project reports and presentations.
  • Small business owners who need invoices, budgets, or sales sheets.
  • Consultants and analysts who turn data into decks.

If you already use an AI helper like Claude Code, Cursor, or GitHub Copilot, this plugs right into it. If you would rather click buttons, the makers also offer a desktop app called AionUi that uses OfficeCLI behind the scenes.

What you can do with it

These features come straight from the README:

  • Create Word, Excel and PowerPoint files from scratch, blank or with content.
  • Read text, layout, styles and formulas, as plain text or in a structured format.
  • Spot problems like messy formatting or styles that do not match.
  • Change anything in a file: text, fonts, colors, layout, formulas, charts and images.
  • Move content around: add, remove, move, or copy parts between documents.
  • Watch it live: a preview opens in your web browser and updates the moment the AI makes a change.
  • Excel formulas that just work: over 350 built-in Excel functions are worked out automatically, so totals show up right away.
  • Pivot tables (summary tables that group your data) with one command.
  • Fill-in templates: design a document once with blanks like {{client}}, then fill it many times with different data. Great for invoices or letters.
  • Learn from a sample: give it a document you like and the AI can study its structure to copy the style.

The README shows sample decks, an annual report, a budget tracker, a gradebook and a sales dashboard, all made entirely by AI using OfficeCLI.

How to start, step by step

What you need first: a Mac, Windows or Linux computer, and an AI helper that can run tools, such as Claude Code, Cursor, Windsurf or GitHub Copilot.

The easiest path, from the README:

  1. Open your AI helper's chat window.
  2. Paste this one line and send it:
curl -fsSL https://officecli.ai/SKILL.md
  1. The AI reads the setup guide and installs everything by itself.
  2. Ask for a file. For example: "Make me a five-slide deck about our Q3 results."
  3. To watch the AI work, ask it to start a live preview. It opens in your browser.

Prefer to install it yourself? On a Mac or Linux, you can run this in Terminal:

curl -fsSL https://raw.githubusercontent.com/iOfficeAI/OfficeCLI/main/install.sh | bash

Not comfortable with any of this? Try the AionUi desktop app instead. You just describe what you want in plain words.

Good to know

  • The tool itself is free. It uses the Apache 2.0 license. In plain words, you can use it, change it, and even use it in paid work, as long as you keep the license notice.
  • Your AI helper may cost money. OfficeCLI is free, but tools like Claude Code or Cursor usually need their own account or plan.
  • Quality depends on your AI. OfficeCLI gives the AI the tools. How good the deck looks still depends on the AI you pair it with.
  • It works on your own computer. The live preview runs on your machine in your browser.
  • Some extras need plugins. Things like PDF export come through add-ons, according to the command list.

The bottom line

OfficeCLI turns your AI helper from a text writer into a real document maker. It builds Word, Excel and PowerPoint files you can open and use, with no Office install needed. If formatting eats your week, this is worth a try.

Get it: github.com/iOfficeAI/OfficeCLI
