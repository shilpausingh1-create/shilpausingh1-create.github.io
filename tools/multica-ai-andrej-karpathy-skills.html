Karpathy Skills: one free file that makes AI coders think first

One free instruction file, based on Andrej Karpathy's advice, that helps AI coding tools ask first, stay simple and only change what you asked.

Developers

stars: 220K · license: MIT · platforms: Works inside Claude Code and Cursor

The problem it solves

You ask an AI coding tool for a small fix. It comes back with a giant rewrite. It changed files you never mentioned. It added features nobody asked for. And it guessed at what you meant instead of asking.

You are not alone. Andrej Karpathy, a well-known AI researcher, wrote about these exact habits. He said AI models make wrong guesses and run with them without checking. He said they like to overcomplicate code, and sometimes change or delete things they do not fully understand.

This project turns his advice into rules your AI tool can follow.

What it is

Karpathy Skills is a single instruction file called CLAUDE.md. Claude Code (an AI coding tool from Anthropic) reads this file at the start of each session and follows what it says. Think of it as a short house-rules sheet for your AI helper.

It was written by the project's author, based on Karpathy's public observations. It is inspired by Karpathy, not made by him.

The file is built around four simple principles.

Who it's for

  • Developers who use Claude Code or Cursor every day.
  • Team leads who want AI-written code that is easier to review.
  • Solo builders and hobby coders tired of AI tools that go overboard.

If you do not use an AI coding tool, this one will not do much for you. It is a set of rules for those tools.

What you can do with it

The file teaches your AI four habits:

  • Think before coding. State its guesses out loud. Ask when unsure. Offer options when a request could mean more than one thing. Push back if there is a simpler way.
  • Simplicity first. Write the least code that solves the problem. No extra features, no "just in case" settings. The README's test: would a senior engineer call this overcomplicated? If yes, simplify.
  • Surgical changes. Touch only what you must. Do not "improve" nearby code or reformat things. If it spots unrelated old code, mention it instead of deleting it. Every changed line should trace back to your request.
  • Goal-driven work. Turn vague asks into checkable goals. "Fix the bug" becomes "write a test that shows the bug, then make it pass." For bigger tasks, list a short plan with a check after each step.

Other things the README covers:

  • Works with Cursor too. The project includes a matching rule file for Cursor.
  • Easy to mix in. You can add it to an existing CLAUDE.md alongside your own project rules.

The README also lists signs it is working: fewer surprise changes, fewer rewrites, and questions that come before the work instead of after a mistake.

How to start, step by step

What you need first: Claude Code installed and working. (For Cursor, see the project's CURSOR.md guide.)

The README recommends installing it as a Claude Code plugin, which makes it work in all your projects.

  1. Open Claude Code.
  2. Add the plugin source by typing:
/plugin marketplace add forrestchang/andrej-karpathy-skills
  1. Install the plugin by typing:
/plugin install andrej-karpathy-skills@karpathy-skills
  1. Keep working as usual. Your AI should now ask more questions up front and make smaller, cleaner changes.

Prefer one project only? In your project folder, run this in Terminal to download the file:

curl -o CLAUDE.md https://raw.githubusercontent.com/forrestchang/andrej-karpathy-skills/main/CLAUDE.md

If you already have a CLAUDE.md, the README shows how to add these rules to the end of it instead of replacing it.

Good to know

  • It favors care over speed. The README says so plainly. For tiny fixes like a typo, use your judgment. Not every change needs the full process.
  • It is guidance, not a guarantee. The file shapes how the AI behaves. It does not change the AI model itself.
  • Cost: the file is free. You still need access to Claude Code or Cursor, which may have their own costs.
  • Privacy: it is just a text file. It does not send anything anywhere.
  • License (MIT): free to use, change and even use in a business. Just keep the license notice.

The bottom line

Karpathy Skills is one small file with a big effect: it nudges your AI coder to ask before acting, keep things simple and stay in its lane. It takes two commands to install. If your AI tool keeps overdoing it, this is the easiest fix to try first.
