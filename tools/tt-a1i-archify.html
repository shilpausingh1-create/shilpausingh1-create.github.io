Archify: describe any idea, get an interactive diagram

Archify is a free AI add-on that turns plain descriptions, plans or code into interactive diagrams saved as one shareable web page.

EveryoneDevelopersEducation

stars: 83K · license: MIT · platforms: Claude Code, Codex, Cursor, OpenCode

The problem it solves

Drawing a diagram by hand takes forever. You drag boxes, line up arrows, fix the spacing, then do it all again when something changes.

And most diagrams are flat pictures. Someone looks at a busy chart and has no idea where to start. They cannot click a box to learn more or follow one path through the mess.

Archify fixes both problems. You describe what you want in plain words. Your AI helper builds a clean diagram you can actually explore.

What it is

Archify is a free, open-source "skill" for AI coding helpers. A skill is a set of instructions an AI follows for a certain kind of job. Archify's job is diagrams.

It works with Cursor, Claude Code, Codex and OpenCode. You tell your AI helper what to draw. It builds the diagram, checks it for problems like overlapping arrows, and saves it as a single web page (an HTML file).

That file is the magic part. Anyone can open it in a web browser. They do not need Archify installed. They can click boxes, trace paths, switch between light and dark themes, and export pictures. Send it to a friend and all the clicking goes with it.

You do not need any code to start. The README says plainly: no repository (code project) is required. A sentence is enough.

Who it's for

  • Teachers explaining a process to a class.
  • Students mapping out a project or study topic.
  • Project managers showing who does what, and in what order.
  • Trip planners. One community member turned a city walking guide into a four-day clickable itinerary.
  • Team leads reviewing how a system works with their team.
  • Developers who want a map of their code, linked back to the actual files.

The README lists community uses in team collaboration, travel planning, legal citation checks, contract review and incident reviews (looking back at what went wrong and when).

What you can do with it

From the README:

  • Start from one sentence. Describe a process and get a diagram. No code needed.
  • Refine by chatting. Say "add authentication," "highlight the cache-miss path," or "switch to the light theme."
  • Pick the right type. It supports architecture, workflow, sequence (who talks to whom, in order), data flow, lifecycle (the stages something goes through), database tables, class, tree, timeline and waterfall (where the time went in one task) diagrams.
  • Explore the result. Click a box for details, trace everything upstream or downstream of a step, search with the slash key, or open a full-screen presentation mode.
  • Export it. Copy a picture to your clipboard, or download images, video and ready-made share cards.
  • Map real code. Ask your AI to read a project and draw it. Boxes can link to the exact files and lines they came from.
  • Compare before and after. A delta view shows what was added, removed or changed between two versions.

How to start, step by step

What you need first: a computer with Node.js installed (a free program that runs many developer tools), and an AI helper such as Cursor, Claude Code, Codex or OpenCode.

  1. Open Terminal (on a Mac) or your command window.
  2. Paste this and press Enter:
npx skills add tt-a1i/archify -g
  1. Open your AI helper.
  2. Describe what you want. The README's example: "Use Archify to diagram a web request: Browser calls the API, the API checks Redis, and a cache miss queries PostgreSQL and fills the cache." You can describe anything, like your hiring process or a weekend trip.
  3. Open the HTML file it makes in your browser.
  4. Keep chatting to change it: "add a step for approval," "move this to the left."

Want to try it before installing? The README shows a one-time "use" command for Codex. You can also browse finished examples on the project's website, archify.si.

Good to know

  • Archify is free. It uses the MIT license. In plain words, you can use it, change it and share it, even for work.
  • Your AI helper may cost money. Tools like Cursor or Claude Code usually need their own account or plan.
  • Privacy note on update checks. The README says Archify may check a fixed web address now and then to show an optional "new version" reminder. It never downloads or installs updates by itself. That check does not send your project, prompts, or account details, though the server sees normal web info like your IP address and the time.
  • Links need the internet. The diagram file works offline, but outside website and map links inside it need a connection.
  • It is not a drawing program. You cannot drag boxes around like in a whiteboard app. You change things by asking your AI. The README says hand-editing and automatic Mermaid conversion are outside its current scope.

The bottom line

Archify turns "can you draw me a diagram?" into a one-sentence job. The result is not a flat picture but a clickable web page anyone can open and explore. For plans, processes, trips or code, it is a big time saver.

Get it: github.com/tt-a1i/archify
