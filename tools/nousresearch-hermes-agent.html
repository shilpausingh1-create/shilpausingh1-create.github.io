Hermes Agent: a free AI assistant that learns and remembers

A free AI assistant from Nous Research that remembers you, builds new skills from experience, and chats with you on Telegram, Slack or WhatsApp.

EveryoneBusinessDevelopers

stars: 254K · license: MIT · platforms: Mac, Windows, Linux

The problem it solves

Most AI chat tools have a short memory. You explain your job, your style and your habits. Next week, it has forgotten. You start over.

They also tend to live in one place, like a browser tab. If you want help from your phone, or want a task done every morning while you sleep, you are often out of luck.

Hermes Agent is built to fix both problems. It remembers what it learns, gets better at tasks over time, and can talk to you wherever you already chat.

What it is

Hermes Agent is a free, open AI "agent." An agent is an AI that does not just answer questions. It can also take actions, like running tools, searching the web or doing tasks on a schedule.

It comes from Nous Research, an AI lab. The README calls it a "self-improving" agent with a built-in learning loop. In plain words: after it finishes a hard task, it can save the steps as a "skill" so it does better next time. It also keeps notes about you, can search your past chats, and builds a better picture of who you are over time.

Hermes is not an AI model itself. It is the helper that sits on top of one. You choose which AI brain it uses.

Who it's for

  • Busy professionals who want an assistant that remembers their work and preferences.
  • Small business owners who want daily reports or reminders sent to their phone.
  • Teams that live in Slack or Discord and want an AI helper right there.
  • Developers who want an agent they can run on their own server and customize.
  • Researchers who want to study how AI agents use tools.

You will need to be okay typing a few commands to set it up. After that, you can chat with it from familiar apps.

What you can do with it

From the README:

  • Chat where you already are: Telegram, Discord, Slack, WhatsApp, Signal, email or a terminal window. It can transcribe voice memos too, and keep one conversation going across apps.
  • Let it learn: it creates skills after complex tasks and improves them as it uses them.
  • Long memory: it keeps notes, searches past conversations, and builds a profile of you over time.
  • Schedule tasks: set up daily reports, nightly backups or weekly checks in plain language. It runs them on its own and sends results to your chosen app.
  • Pick any AI model: use Nous Portal, OpenRouter, OpenAI, your own setup and many others. Switch with one command, with no lock-in.
  • Split up big jobs: it can start helper agents to work on several things at once.
  • Run it anywhere: on your own computer, or on a cheap rented server. The README says even a $5 server works, so it can keep going while your laptop is off.
  • Move over from OpenClaw: if you used the OpenClaw assistant, Hermes can import your settings, memories and skills.

How to start, step by step

What you need first: a Mac, Windows or Linux computer, and an account with an AI provider (for example OpenRouter, OpenAI or Nous Portal). The AI provider is where the "brain" comes from.

  1. Open Terminal (Mac or Linux) and paste the one-line installer:
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash

On Windows, open PowerShell and run iex (irm https://hermes-agent.nousresearch.com/install.ps1) instead.

  1. Reload your terminal by typing source ~/.bashrc (or source ~/.zshrc on most Macs), or just open a new window.
  2. Run the setup wizard by typing hermes setup. It walks you through picking an AI model and connecting your account.
  3. Type hermes and start chatting.
  4. Optional: to chat from Telegram, Slack or another app, run hermes gateway setup and then hermes gateway start.

Good to know

  • The AI model may cost money. Hermes is free, but the AI provider you pick may charge you. Nous also offers Nous Portal, a paid subscription that bundles 300+ models plus web search, image making and voice tools under one account. You can bring your own keys instead.
  • Antivirus warnings on Windows: some antivirus apps flag a helper file called uv.exe. The README says this is a false alarm and explains how to check it.
  • It can take real actions. Because it can run commands, read the security guide in the docs. It covers approving commands and keeping it in a safe container.
  • License (MIT): free to use, change and even use in a business. Just keep the license notice.

The bottom line

Hermes Agent is a free AI helper that remembers you, gets better with use, and meets you in the chat apps you already use. Setup takes a few commands, and you pay only for the AI model you choose. It is a strong pick if you want one assistant that grows with you.

Get it: github.com/NousResearch/hermes-agent
