Security Audit: Cloudflare's free add-on that checks your code

Cloudflare's free add-on that turns your AI coding helper into a careful security reviewer and writes a clear report of real problems.

DevelopersBusiness

stars: 30K · license: MIT · platforms: AI coding agents (Claude Code, Codex and others)

The problem it solves

More people than ever are building apps with AI helpers. That's exciting. But speed has a downside.

It's easy to ship an app that works but has hidden security holes. A login that can be skipped. Customer data that can leak. A form that lets strangers run commands.

Hiring a security expert costs a lot. Many small teams and solo builders just hope for the best.

Cloudflare's Security Audit skill gives you a careful, structured check instead of hope.

What it is

Security Audit is a free, open-source "skill" from Cloudflare, the big internet security company. A skill is an add-on that teaches your AI coding helper a new job.

This one turns your AI helper into a security auditor. It sends several separate AI helpers through your code in an orderly way, then double-checks what they find.

Cloudflare says this skill was the seed of its own vulnerability-finding system, which later grew into a much larger tool used across the company. This skill is the single-project starting point.

Who it's for

  • Developers who want a security review before launch.
  • "Vibe coders" and solo builders who make apps with AI and aren't security experts.
  • Startups and small businesses that can't yet afford a full security firm.
  • Security teams who want a repeatable first pass on a codebase.

You need to be using an AI coding helper like Claude Code or Codex.

What you can do with it

The skill runs an audit in six phases:

  1. Reconnaissance: it maps how your app is built, where outside input comes in, and where the trust boundaries are (the lines between safe and unsafe areas).
  2. Coverage-led hunting: separate AI "hunters" each check assigned parts of the code, and "critics" look for gaps they missed.
  3. Candidate validation: every possible problem goes to a fresh AI checker whose job is to prove it wrong.
  4. Structured output: results are sorted into confirmed, needs checking, or rejected.
  5. Independent record verification: new AI helpers check the final claims against the actual code again.
  6. Reporting: it writes clear reports, including a main report, finding details, and a list of open questions.

Other things it does:

  • Checks many kinds of risk, from web logins and browser code to cloud setups, AI prompt tricks, mobile apps and software supply chains.
  • Gets better with repeat runs. Each run builds on the last. Cloudflare says that in its tests, one run found about half the problems that repeated runs found in total.
  • Answers smaller security questions too, not just full audits.
  • Keeps the reports out of your project folder by default, saving them in a separate audits folder.

How to start, step by step

You need an AI coding helper that supports tool use and parallel helpers, plus Node.js (a free tool that runs JavaScript programs).

  1. Open Terminal and install the skill:
npx skills add https://github.com/cloudflare/security-audit-skill \
  --skill security-audit

Add --global to install it for every project on your computer.

  1. Open your AI helper inside your project folder.
  2. Ask it for an audit, for example:
security audit this codebase

You can also say "find security vulnerabilities in ./src" or "do a security review, output to ~/audits/my-project".

  1. Read the reports. By default they're saved in ~/security-audit-skill/<your-project-name>/.

Good to know

  • It uses your AI helper's usage. A full audit sends many AI helpers through your code. That can use a lot of your AI plan. Check what your plan allows or costs.
  • Safety first for running code. The README says testing your code by actually running it should happen in a locked-down sandbox (a sealed-off space with no internet). Without one, the skill marks a problem as "needs checking" instead of running your code.
  • It's careful about claims. It only marks a problem "confirmed" when it can trace it through the code. Missing extra layers of defense are noted as hardening tips, not as holes.
  • It's not a guarantee. No tool finds every problem. Running it more than once finds more.
  • MIT license means you can use, change and share it for free, even in a business. Just keep the copyright notice.

The bottom line

Security Audit gives anyone with an AI coding helper a structured, double-checked security review for free. It comes from a company that lives and breathes internet security. Run it before you launch, and run it again after big changes.

Get it: github.com/cloudflare/security-audit-skill
