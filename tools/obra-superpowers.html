Superpowers: make your AI coder plan before it builds

Free skills that make AI coding helpers ask questions, write a plan, test and review their work like a careful engineer.

DevelopersBusiness

stars: 299K · license: MIT · platforms: Works inside Claude Code and other AI coding tools

The problem it solves

AI coding helpers are fast. Sometimes too fast. You ask for an app and they start typing code right away. They guess what you meant. They skip tests. Then something breaks, and you spend hours untangling it.

This hits non-programmers hardest. If you are a founder or a hobbyist "vibe coding" (building apps by chatting with AI), you may not spot a bad guess until it is too late.

What it is

Superpowers is a free set of "skills" for AI coding helpers. A skill is a set of written instructions the AI follows for a certain kind of job. Together, these skills give the AI a full working method, like a careful engineer would use.

The big idea: when the AI sees you are building something, it does not jump into code. It first asks what you are really trying to do. It shows you a design in short, readable chunks. Once you approve, it writes a clear step-by-step plan. Then it works through the plan, checking its work as it goes.

The skills start on their own. You do not need to remember special commands.

Who it's for

  • Founders and product people who build with AI and want fewer surprises.
  • Hobbyists and vibe coders who are not engineers but want solid results.
  • Professional developers who want their AI helper to test and review itself.
  • Teams that want one shared, steady way of working with AI.

What you can do with it

  • Brainstorm first. Before building, the AI asks questions to draw out what you want and why, then plays it back to you.
  • Get a written plan. Work is split into small tasks of 2 to 5 minutes, each with exact steps and checks.
  • Work in a safe copy. It sets up a separate workspace so your main project stays clean.
  • Test first. It writes a failing test, then the code to make it pass. This is called test-driven development (checking work before it ships).
  • Review between tasks. It checks work against the plan and flags problems by how serious they are.
  • Debug step by step. A four-step process to find the real cause of a bug.
  • Confirm it is really fixed before saying it is done.
  • Finish cleanly. When tasks are done, it checks tests and offers options like merging or keeping the work.
  • Ask what went wrong. If a session misbehaves, ask it to figure out what happened and it reports back with evidence.

The README says it is common for the AI to work on its own for a couple of hours without leaving the plan.

How to start, step by step

You need an AI coding helper first. Superpowers works with Claude Code (Anthropic's AI coding helper), plus Codex, Cursor, Gemini CLI, GitHub Copilot CLI, OpenCode and several others. Each tool needs its own install.

For Claude Code:

  1. Open Claude Code.
  2. Install the plugin from Anthropic's official marketplace by typing:
/plugin install superpowers@claude-plugins-official
  1. Describe what you want to build. For example, "Let's make a to-do list app." The brainstorming skill should start on its own and ask you questions.
  2. Answer the questions and approve the design. Then let it write the plan and say "go."

Using Cursor? In Cursor's agent chat, type /add-plugin superpowers. In the Codex app, click Plugins in the sidebar and add Superpowers. The README has steps for each other tool.

Good to know

  • Free skills, paid AI. Superpowers is free. The AI coding helper you use may need its own paid plan.
  • It takes a bit longer up front. Questions and planning add time at the start, in exchange for fewer mistakes later.
  • Small logo telemetry. An optional visual feature loads a logo from the makers' website, which tells them the version in use. It does not send your project, prompts or code. You can turn it off with a setting.
  • Updates. The README says updates are often automatic, depending on your tool.
  • Business help. The makers, Prime Radiant, offer paid support for companies. The README does not list prices.
  • License: MIT. Free to use, change and even use in business. Just keep the copyright notice.

The bottom line

Superpowers teaches your AI coder good habits: ask first, plan clearly, test, and review. If your AI helper keeps rushing and breaking things, this is a simple fix. Install it with one command and describe your next idea.
