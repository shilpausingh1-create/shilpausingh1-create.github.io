MemPalace: give your AI a private memory of past chats

A free memory system that saves your AI conversations word for word on your own computer and finds the right ones when you need them.

DevelopersEveryone

stars: 60K · license: MIT · platforms: Mac, Windows, Linux

The problem it solves

You spend an hour with your AI assistant working through a tricky project. You make decisions. You explain why. The next day you open a new chat, and it remembers none of it. So you explain it all again.

Some tools try to fix this by writing short summaries of your past chats. But summaries lose details. The one thing you need later is often the thing that got cut.

MemPalace takes a different path. It keeps your conversations word for word, on your own computer, and pulls up the right pieces when you ask.

What it is

MemPalace is a free AI memory system. It saves your conversation history as exact text. It does not summarize or rewrite anything.

To find things later, it uses "semantic search," which means searching by meaning, not just exact words. Ask "why did we switch to GraphQL" and it can find the chat where you discussed it, even if you used different words back then.

It organizes memories like a building, which is where the name comes from. People and projects become "wings." Topics become "rooms." The original text lives in "drawers." This lets searches stay focused on one project instead of digging through everything.

The README says nothing leaves your computer unless you choose to allow it.

Who it's for

  • Developers who use AI coding tools like Claude Code, Codex or Cursor every day.
  • People who work on long projects with AI and hate repeating themselves.
  • Teams who want a shared AI memory they host themselves.
  • Anyone who wants AI memory without sending their chats to another company's cloud.

To be honest, setup today is aimed at people who are comfortable with a terminal and AI coding tools. The easiest path lets your AI assistant do the setup for you.

What you can do with it

From the README:

  • Save chats word for word: no summaries, no lost details.
  • Search by meaning: find past talks even if you forget the exact words.
  • Load context for a new session: the wake-up command gives a fresh chat the background it needs.
  • Save your project files too, not just chats.
  • Auto-save: hooks for Claude Code, Codex CLI and Cursor save your sessions on a schedule and before the AI trims its memory.
  • Track facts over time: a built-in "knowledge graph" records how things relate and when facts changed.
  • Connect to AI tools: it offers 47 tools through MCP (a standard way for AI apps to plug into other software).
  • Choose your setup: a private palace on your computer, a shared team "hub," or a connection to an existing hub.
  • Strong test scores: on a memory test called LongMemEval, the README reports 96.6% of the right answers found in the top 5 results, with no AI model or internet needed.

How to start, step by step

What you need first: an AI coding assistant such as Claude Code, Node.js (to run the first command), and Python 3.9 or newer. You also need about 300 MB of free space for the search model.

The README's guided path lets your AI assistant handle setup:

  1. Open Terminal and add the MemPalace skills (instructions your AI can follow):
npx skills add MemPalace/mempalace
  1. Open your AI coding assistant and ask it to set up MemPalace.
  2. It checks your system, installs what is needed and connects everything.
  3. When asked, pick a private local palace if you just want memory on your own computer.
  4. Start using it. You can also search directly, for example with mempalace search "why did we switch to GraphQL".

Prefer to do it yourself? The README recommends uv tool install mempalace, then mempalace init on your project folder.

Good to know

  • Watch out for fake sites. The README warns that impostor websites exist and may spread malware. The only official sources are the GitHub page, the PyPI package and mempalaceofficial.com.
  • Claude Code users, read this: the README warns that Claude Code sessions expire after 30 days unless auto-save hooks are set up. It links to a setup checklist.
  • Privacy: core use needs no API key and no cloud. You can choose to use a server for some parts, but that is opt-in.
  • Update checks are off by default and never install updates on their own.
  • Cost: free. No paid service is required.
  • Phones: Android is not directly supported, though there is a workaround guide.
  • License (MIT): free to use, change and even use in a business. Just keep the license notice.

The bottom line

MemPalace gives your AI a long memory that stays on your own computer and keeps every word. Your AI assistant can set it up for you in a few steps. If you are tired of re-explaining your projects every day, it is worth a look.
