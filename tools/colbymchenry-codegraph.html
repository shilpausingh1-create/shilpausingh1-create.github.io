CodeGraph: help your AI coder find the right code in one step

CodeGraph builds a ready-made map of your code on your own computer, so AI coding helpers find what they need with fewer steps and less cost.

DevelopersBusiness

stars: 74K · license: MIT · platforms: Mac, Windows, Linux

The problem it solves

You ask your AI coding helper a question about your project. Before it can answer, it has to go looking. It searches. It lists folders. It opens a file, then another, then another.

All that digging takes time. It also costs money, because AI tools charge by the token (a small chunk of text the AI reads or writes). On a big project, the AI can spend most of its effort just finding its way around.

It is like asking a new hire to find one invoice in a warehouse with no labels on the boxes.

What it is

CodeGraph is a free, open-source tool that builds a map of your code ahead of time. It records every piece of your code and how the pieces call and depend on each other. This kind of map is called a knowledge graph.

When your AI helper needs something, it asks the map. In one step it gets back the right code, how that code connects to other parts, and what a change might affect. No more opening files one by one.

Everything runs on your own computer. Nothing is uploaded.

Who it's for

  • Developers who use Claude Code, Cursor, Codex or similar tools every day.
  • Teams with large projects, where AI helpers waste the most time searching.
  • Freelancers and small businesses watching their AI bills.
  • Anyone working with sensitive code who wants their tools to stay local.

If you do not use an AI coding helper, this tool is not for you yet.

What you can do with it

  • Give your AI the right code in one call, instead of many searches.
  • Cut AI costs. In the makers' own tests on seven open-source projects, the AI used 88% fewer tool calls, ran 53% faster, used 62% fewer tokens and cost 44% less on average.
  • See the impact of a change before you make it. It shows what calls a piece of code and what that code calls.
  • Search your code by name, instantly.
  • Stay up to date on its own. It watches your project and updates the map every time a file changes. There is nothing to re-run.
  • Work across 20+ programming languages, including Python, JavaScript, Java, Swift and many more.
  • Understand web routes, linking web addresses to the code that handles them, across 17 popular frameworks.
  • Connect to many AI tools, including Claude Code, Cursor, Codex, Gemini, Kiro and GitHub Copilot.

How to start, step by step

What you need first: a Mac, Windows or Linux computer, and an AI coding tool such as Claude Code or Cursor. You do not need Node.js for the main installer.

  1. Open Terminal (Mac or Linux) or PowerShell (Windows).
  2. Install CodeGraph. On a Mac or Linux:
curl -fsSL https://raw.githubusercontent.com/colbymchenry/codegraph/main/install.sh | sh

On Windows, the README gives a PowerShell version. If you already have Node.js, you can use npm i -g @colbymchenry/codegraph instead.

  1. Open a new Terminal window. The README says this is needed so the new command works.
  2. Connect CodeGraph to your AI tools:
codegraph install

It finds the AI tools on your computer and sets them up. Restart your AI tool after this.

  1. Go into your project folder and build the map:
cd your-project
codegraph init
  1. That is it. Use your AI tool as normal. The map keeps itself up to date.

To remove it later, run codegraph uninstall.

Good to know

  • It runs 100% on your computer. The README says no data leaves your machine, no API keys are needed and no outside services are used.
  • There are anonymous usage stats. The makers collect counts of which commands and languages get used. They say they never collect code, file names, searches or IP addresses. The installer asks first, and codegraph telemetry off turns it off.
  • Savings vary. The cost savings depended a lot on the project. On some test projects it was over 70% cheaper. On others it was about even.
  • One honest trade-off. The makers note that CodeGraph's answers can leave more text sitting in the AI's short-term memory (its context window) during long chats.
  • The first map takes some time on very big projects. After that, updates take well under a second.
  • A paid hosted product is coming. The makers are offering early beta access to a separate platform. The free tool works without it.
  • License: MIT. You can use, copy and change it for free, even at work. Just keep the copyright notice.

The bottom line

CodeGraph gives your AI coding helper a labeled map instead of a dark warehouse. It installs in a few commands, keeps itself current and never sends your code anywhere.
