Diagram Design: clean, magazine-style diagrams from one sentence

Diagram Design is a free AI add-on that turns plain-English requests into clean, on-brand diagrams saved as one easy-to-open file.

DesignMarketingCreators

stars: 55K · license: MIT · platforms: Claude Code, Codex, Cursor, Copilot and other AI agents

The problem it solves

Ask an AI for a diagram and you often get a mess. Rounded boxes everywhere. Too many colors. Shadows. Arrows crossing each other. It looks nothing like the rest of your slides, blog or website.

The creator of this tool, Cathryn Lavery, hit the same wall. She wanted nice diagrams for her blog posts. Every time she asked an AI, she got back a generic box drawing. As she puts it in the README, the AI already understood the content. What it was missing was taste.

So she wrote the taste down.

What it is

Diagram Design is a free, open-source "skill" for AI helpers. A skill is a set of instructions an AI follows for a certain kind of job. This one makes diagrams in a clean, editorial style, like you would see in a good magazine.

You ask in plain words. The AI picks the right diagram type, tells you its plan, and writes one HTML file. You double-click that file to open it in your browser.

It follows a strict style. One accent color, used only for the one or two things that matter most. Thin lines. No shadows. Everything lined up on a neat grid. The README's motto: "The highest-quality move is usually deletion."

It offers 45 diagram types. And it can match your own brand's colors and fonts.

Who it's for

  • Bloggers and newsletter writers who want diagrams that match their site.
  • Marketers making charts for decks, posts and landing pages.
  • Consultants and agencies who work for several clients with different brands.
  • Teachers and trainers explaining ideas visually.
  • Founders building pitch decks.
  • Developers documenting how their apps work.

You need an AI helper that supports skills. The README lists Cursor, Claude Code, Codex, GitHub Copilot, Gemini CLI, Cline, Windsurf and Amp.

What you can do with it

From the README:

  • Ask in plain words. For example: "I need a quadrant showing Q2 projects by impact vs effort."
  • 45 diagram types, each in three looks: light, dark, and a fuller editorial version with summary cards. These include architecture maps, flowcharts, sequences, quadrants, pyramids, line and scatter charts, treemaps and even exploded product views like a phone teardown.
  • Match your brand. Say "onboard diagram-design to" followed by your website address. It pulls your colors and fonts, shows you the changes, and uses them for every diagram after that.
  • Automatic contrast checks. It checks that text is easy to read against the background, and suggests a fix if your brand color is too faint.
  • Multiple clients. Save each brand as a profile and switch between them by project.
  • Redraw old diagrams. Point it at a draw.io, Mermaid or Excalidraw file and it redraws it in this cleaner style. You can choose the size (slide, social post, print), the detail level, and the audience (engineer, mixed or executive).
  • Export to PNG or SVG for slides, Figma or social cards.
  • Accessible by default. Diagrams include a title and description that screen readers can announce.
  • Optional motion, with a full still version for people who prefer reduced motion.

How to start, step by step

What you need first: a computer with Node.js installed (a free program that runs many developer tools), and a supported AI helper.

  1. Open Terminal (on a Mac) or your command window.
  2. Paste this and press Enter:
npx skills add cathrynlavery/diagram-design
  1. Open your AI helper.
  2. Optional but recommended: say "onboard diagram-design to" plus your website address, so diagrams match your brand.
  3. Ask for a diagram in one sentence. For example: "Make me an architecture diagram of my app: frontend, backend, database, Redis cache."
  4. Double-click the HTML file it creates to open it.

Using Claude Code? You can also install it from its plugin marketplace, which gives you automatic updates and extra slash commands:

/plugin marketplace add cathrynlavery/diagram-design
/plugin install diagram-design@diagram-design

Good to know

  • It is free. It uses the MIT license. In plain words, you can use it, change it and share it, even for client work.
  • Your AI helper may cost money. Most supported helpers need their own account or plan.
  • Results vary. The README is honest: output quality depends on the AI model you use, and the same request can come out laid out differently twice.
  • Not easy to hand-edit. The result is not a drag-and-drop file. To change it, you ask the AI again or edit the image code. For diagrams that change every week in a code project, the README suggests a text-based tool like Mermaid instead.
  • Privacy note. By default a diagram loads three fonts from Google Fonts, its only network request. Ask for system fonts and it makes no network requests at all. The project has a privacy file listing what the skill sends.
  • PNG export needs a one-time setup of a free tool called Playwright.
  • Get the real one. Official builds come only from this GitHub repository.

The bottom line

Diagram Design gives your AI helper good taste. One sentence gets you a clean, on-brand diagram you can drop into a deck, post or doc. If AI diagrams usually make you wince, this is the fix.
