Headroom: same AI answers, a much smaller token bill

Headroom shrinks the logs, files and data your AI reads, right on your computer, so you pay for fewer tokens and get the same answers.

DevelopersBusinessFinance

stars: 75K · license: Apache-2.0 · platforms: Mac, Windows, Linux

The problem it solves

AI tools charge by the token. A token is a small chunk of text, roughly part of a word. Every word your AI reads costs money. Every word it writes back costs money too.

Now picture what an AI coding helper reads all day. Long error logs. Search results. Big files. Data dumps full of the same lines repeated again and again. Most of it is filler. But you pay for every bit.

For heavy users, this is where the bill quietly balloons.

What it is

Headroom is a free, open-source tool that shrinks everything your AI reads before it reaches the AI. That includes tool results, logs, files, search results and chat history.

The idea is simple: same answers, a fraction of the tokens. The README shows an example where a log of 10,144 tokens was shrunk to 1,260 tokens, and the AI still found the one important error line.

The shrinking happens on your own computer. Your prompts and files are not sent anywhere to be compressed.

Nothing is thrown away, either. Headroom keeps the original text on your computer. If the AI needs the full version, it can ask for it.

Who it's for

  • Heavy users of AI coding tools like Claude Code, Codex or Cursor.
  • Developers building AI apps who want lower running costs.
  • Support and operations teams whose AI reads long logs to find problems.
  • Startups and finance teams keeping an eye on monthly AI spending.
  • Anyone who hits usage limits on their AI plan too quickly.

What you can do with it

  • Wrap your AI tool in one command. headroom wrap claude starts Claude Code through Headroom. It also works with Codex, Copilot, Aider, OpenCode, Cline and more. Undo it with headroom unwrap.
  • Watch your savings live with headroom dashboard.
  • Shrink what the AI writes back. An optional setting asks the AI to skip filler like long intros and repeated code.
  • Share memory across AI tools, so Claude, Codex, Gemini and Grok can use one shared store.
  • Learn from mistakes. headroom learn looks at failed sessions and writes fixes into your AI's instruction file.
  • Use it in your own app. Developers can call it from Python or TypeScript code.
  • Run it as a proxy (a middle step all AI traffic passes through), with no code changes.

How much does it save? In the makers' tests on four real-world examples, savings ran from 21% to 57%. They say very repetitive data, like repeated log lines, can shrink by over 90%. Plain writing shrinks very little. In their accuracy tests, answers stayed about the same.

How to start, step by step

What you need first: a computer with Python 3.10 or newer, and an AI coding tool such as Claude Code.

  1. Open Terminal (Mac or Linux) or PowerShell (Windows).
  2. Install Headroom:
pip install "headroom-ai[all]"

The README also offers a uv tool install option, which keeps it neatly separate from other Python tools.

  1. Start your AI tool through Headroom. For Claude Code:
headroom wrap claude

Launch it this way each time so the savings apply.

  1. Check that it works:
headroom doctor
  1. In another Terminal window, open the savings dashboard:
headroom dashboard

Using Cursor? It needs a manual step. Headroom starts the proxy and prints the addresses to paste into Cursor's settings.

Good to know

  • The tool is free. You still pay your AI provider, just for fewer tokens.
  • Compression is local. The README says no prompt or file content is sent anywhere to be compressed.
  • Anonymous stats are on by default. Headroom reports how well compression worked, plus your system type and AI model names. It never sends prompts, answers, code or file paths. Turn it off with the setting HEADROOM_BEACON=off.
  • It adds a helper tool. headroom wrap also installs a code navigation tool called Serena for that project. You can skip it with --code-memory none.
  • Savings depend on your data. Repetitive logs save a lot. Plain text saves little. Run headroom savings to see your real number.
  • There is a paid team version. Headroom Enterprise adds extra features for teams. The free version is built for one person on one laptop.
  • The npm package is different. It is only for developers' code and does not include the headroom command.
  • License: Apache-2.0. You can use, change and use it at work for free. Just keep the copyright notice.

The bottom line

Headroom trims the filler from what your AI reads, on your own computer, so you get the same answers for fewer tokens. If your AI bill or usage limits sting, it is a quick win to try.

Get it: github.com/headroomlabs-ai/headroom
