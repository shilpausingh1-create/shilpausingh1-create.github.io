Pake: turn any website into a tiny desktop app for free

Turn any website into a small, fast desktop app, often under 10 MB, with ready-made apps for ChatGPT and more.

EveryoneBusinessDevelopers

stars: 62K · license: GPL-3.0 · platforms: Mac, Windows, Linux

The problem it solves

Many of us live in a few websites all day. ChatGPT, Gemini, Notion, YouTube Music. They sit in a sea of browser tabs. You lose them, close them by accident, or hunt for the right tab ten times an hour.

Some sites offer desktop apps, but many of those are big and hungry for memory. Others do not offer an app at all.

What it is

Pake is a free, open-source tool that turns any webpage into its own desktop app with one command. The app gets its own window and icon, just like a normal program.

The apps are small. The README says the installer is nearly 20 times smaller than apps built with Electron (a common, heavier way to make desktop apps), and typically under 10 MB on disk. Pake is built with Rust and Tauri, which are tools that make apps fast and light on memory.

It works on Mac, Windows and Linux.

Who it's for

  • Office workers who want Notion, ChatGPT or a team tool in its own window.
  • Writers and students who keep AI chat apps open all day.
  • Music lovers who want YouTube Music as a separate app.
  • Designers who use web tools like Excalidraw (a free sketching whiteboard).
  • Small business owners who want a simple desktop app for their own website.
  • Developers who want to package a web tool for their team.

What you can do with it

  • Download ready-made apps. No setup. The README offers apps for ChatGPT, Gemini, Grok, DeepSeek, YouTube, YouTube Music, Twitter, Notion, Excalidraw, and more, for Mac, Windows and Linux.
  • Make an app from any site with one command. It grabs the site's icon automatically.
  • Customize it. Choose your own icon, window size, and hide the title bar.
  • Build online. Skip the command line by using the project's online building option on GitHub.
  • Use handy shortcuts. Go back and forward, zoom, refresh, copy the page link, and clear cache.
  • Extra features. Immersive windows, drag and drop, style changes, and ad removal.
  • Hide instead of quit. Closing the window hides it, so your app stays ready.
  • Let AI do it. Pake has an official skill for AI helpers like Claude Code and Codex.

How to start, step by step

The easiest way (no setup):

  1. Open the Pake page on GitHub.
  2. Scroll down to Popular Packages.
  3. Click your app (for example, ChatGPT) and pick Mac, Windows or Linux.
  4. Install it like any other app and open it.

More apps are on the project's Releases page.

Make your own app from any website:

First you need: Node.js and pnpm (free tools that install small programs from the command line).

  1. Open Terminal and install the Pake tool:
pnpm install -g pake-cli
  1. Turn a site into an app. For example:
pake https://github.com --name GitHub
  1. Wait. The first build sets things up and takes a while. Later builds are fast.
  2. Open your new app.

Not a fan of typing commands? The README links to a guide for building apps online through GitHub instead.

Good to know

  • It is still the website. The app shows the real website in its own window. You still log in and need internet like normal.
  • First build is slow. Making your own app the first time takes a while as it sets up.
  • Free to use. No paid services are needed. The creator also sells a separate paid Mac cleanup app called Mole, but you do not need it.
  • Apps you build are yours. The README says apps you make with Pake are entirely yours to use and share.
  • License. Pake uses GPL-3.0 with a special exception for output apps. In plain words: the tool is free to use and change, and if you share a changed version of Pake itself, you must share your code too. If you fork it into your own product, the author asks you to rename it and credit Pake.
  • Developers going deeper need Rust and Node to build Pake from source.

The bottom line

Pake turns the websites you use most into small, fast desktop apps. Start by downloading a ready-made app like ChatGPT or Notion, no setup needed. If you want more, one command can turn almost any site into its own app.

Get it: github.com/tw93/Pake
