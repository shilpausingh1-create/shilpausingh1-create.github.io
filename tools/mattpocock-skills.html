Matt Pocock's Skills: make your AI coder actually listen

A well-known coding teacher's own set of AI skills that help coding assistants ask better questions, stay on track and build cleaner software.

DevelopersBusinessStudents

stars: 291K · license: MIT · platforms: Works with Claude Code, Cursor, OpenCode, and more

The problem it solves

You ask your AI coding helper to build something. It gets to work right away. Ten minutes later, you look at the result and think: that is not what I meant at all.

Or it writes three paragraphs where one word would do. Or the code looks fine but does not actually work. Or, after a few weeks, your project has turned into a tangled mess that nobody wants to touch.

These are not rare problems. They are the most common ways AI coding goes wrong.

What it is

Skills is a free collection of add-ons from Matt Pocock, a well-known TypeScript teacher. He says in the README that these are the skills he uses every day to do "real engineering," not quick "vibe coding."

A skill is a saved set of instructions your AI follows for a certain job. Think of it like a recipe card you hand to a new cook. Instead of explaining the same thing every time, you say "use this skill" and the AI knows what to do.

The skills are small, easy to change and work with any AI model. Matt built them to fix the problems he kept seeing with tools like Claude Code and Codex.

Who it's for

  • Developers who use AI coding helpers every day.
  • Founders and solo builders who rely on AI to write most of their code.
  • Product managers and planners who want to think through an idea before anyone builds it.
  • Students learning good engineering habits alongside AI.
  • Teams that want their AI to follow the same process every time.

Some skills are not about code at all. The /grill-me skill, for example, is for any plan or idea.

What you can do with it

  • Get grilled before you build. /grill-me makes the AI ask you detailed questions about your plan until every open question is answered. Matt says these grilling skills are his most popular.
  • Build a shared language. /grill-with-docs creates a glossary of your project's terms, so the AI stops using 20 words where one will do.
  • Write tests first. /tdd guides the AI to write a failing test, then make it pass. This gives the AI quick feedback on whether its code works.
  • Hunt down hard bugs. /diagnosing-bugs runs a careful, step-by-step debugging loop.
  • Turn talk into tasks. /to-spec writes up a plan from your chat. /to-tickets breaks a plan into small tasks.
  • Keep the code tidy. /improve-codebase-architecture looks for ways to clean up your code and shows them in a visual report.
  • Get a second opinion. /code-review checks changes against your coding rules and the original plan.
  • Hand off work. /handoff sums up a chat so another AI session can pick it up.
  • Learn something new. /teach teaches you a skill or idea over several sessions.
  • Ask for plain English. /wait-what re-explains a confusing message with the context you were missing.
  • Not sure where to start? /ask-matt points you to the right skill.

How to start, step by step

What you need first: an AI coding assistant, such as Claude Code, Codex, GitHub Copilot, Gemini CLI or Cursor. You will type a command into Terminal.

  1. Open Terminal.
  2. Install the skills. For Claude Code, the README gives this command:
claude plugin install mattpocock-skills@claude-plugins-official

For other assistants, like Cursor or OpenCode, use:

npx skills@latest add mattpocock/skills

If it asks which skills to take, include setup-matt-pocock-skills.

  1. Open your project in your AI assistant.
  2. Run the setup skill once per project:
/setup-matt-pocock-skills
  1. Answer its few questions. It asks which issue tracker you use (like GitHub or plain local files), what labels you use for tasks, and where to save documents.
  2. Start using the skills. A good first one is /grill-me before your next change.

Pick one install method per assistant. The README warns that installing both gives you every skill twice.

Good to know

  • The skills are free. But your AI assistant may have its own costs.
  • The plugin updates itself. If you install with npx skills, you update by hand instead.
  • They are meant to be changed. Matt encourages you to adapt them and make them your own.
  • It will not fix everything. He says the architecture skill finds ideas to improve, but will not untangle a messy project for you.
  • There is a free newsletter if you want updates on new skills. It is optional.
  • License: MIT. In plain words, you can use, copy and change the skills for free, even at work. Just keep the copyright notice.

The bottom line

Matt Pocock's Skills bottle up years of good engineering habits into short commands your AI can follow. Start with /grill-me and you may never get "that is not what I asked for" again.
