ECC: hundreds of ready-made skills for your AI coding helper

A big free toolkit that gives AI coding helpers 71 agents, 311 skills, memory and built-in security checks.

Developers

stars: 279K · license: MIT · platforms: Works with Claude Code, Codex, Cursor, OpenCode

The problem it solves

An AI coding helper out of the box is a bit like a new hire with no training. It can write code, but it does not know your team's habits. It forgets the plan halfway through. It reviews its own work with the same blind spots it wrote it with. And every new chat, you explain the same things again.

Setting all of that up yourself takes weeks of trial and error.

What it is

ECC is a free, open-source toolkit that you install into your AI coding helper. It works best with Claude Code (Anthropic's AI coding helper) and also supports Codex, Qoder and, with fewer features, Cursor, OpenCode, Gemini and others.

It gives the AI a working routine: plan, test, build, review, verify, remember, improve. You install that routine once, instead of typing it into every prompt.

Inside are 71 agents, 311 skills and 97 older shortcut commands. An "agent" is a helper with one focused job, like planning or reviewing. A "skill" is a written recipe the AI follows for a task. It also includes memory tools and a security scanner called AgentShield.

Who it's for

  • Developers using Claude Code who want a strong setup without building it from scratch.
  • Teams who want one shared way of planning, testing and reviewing with AI.
  • People using several AI coding tools who want to pass notes between them.
  • Security-minded builders who want their AI setup checked for risky settings.

This one is honestly for people who write software. If you have never opened a code project, start with something simpler.

What you can do with it

  • Plan before building. A planner agent writes a blueprint you can edit before any code is written.
  • Test first. A test-driven workflow writes a failing test, then the code to make it pass.
  • Get a fresh review. A separate reviewer checks the work with a clean slate, so it catches more.
  • Fix broken builds. Dedicated helpers for build errors in many programming languages.
  • Review code by language. Reviewers for Python, Go, TypeScript, Java, Rust, Kotlin, C++ and more.
  • Scan for security risks. AgentShield checks your AI setup files for leaked secrets, risky permissions and hidden attack tricks.
  • Block dangerous commands. A guard checks risky delete commands before they run.
  • Remember across tools. A "Memory Vault" keeps notes in plain files that Claude, Codex and others can read.
  • Learn your habits. It can turn patterns from your sessions into reusable skills.
  • Save and resume sessions so long projects pick up where they left off.
  • Use beyond code. Some skills cover article writing, market research and pitch decks.

How to start, step by step

You need three things first: Node.js 18 or newer (a free tool many apps need), Git (a free tool for tracking code changes), and Claude Code version 2.1 or newer.

  1. Check your tools. Open Terminal (Mac) or PowerShell (Windows) and type node --version, git --version and claude --version. Each should print a number.
  2. Run the guided setup:
npx ecc-universal@2.2.3 setup
  1. Pick your options. For a typical personal setup, the README suggests choosing "Global user," then "Standard" hooks, then confirm.
  2. Check it worked. Start a new Claude Code session and type /plugin list. You should see ecc@ecc turned on.
  3. Try it. Type /ecc:plan "describe the feature" to have it plan your next feature.

Prefer doing it inside Claude Code? Type /plugin marketplace add https://github.com/affaan-m/ECC, then /plugin install ecc@ecc. Pick one install method only. Installing twice can make things run twice.

Good to know

  • Official sources only. The README warns that copies posted elsewhere may contain malware. Install only from the GitHub page, the npm packages ecc-universal or ecc-agentshield, or ecc.tools.
  • The toolkit is free. A paid "ECC Pro" version adds checks for private code projects, starting at $19 per seat per month, per the README.
  • AI costs are separate. Your AI coding helper may have its own fees. The README includes tips to cut token use (the units AI services bill by), like using a cheaper model for most tasks.
  • Do not turn on everything. Too many add-on tools can crowd the AI's short-term memory. The README suggests keeping it lean.
  • Not equal everywhere. Claude Code gets the full feature set. Other tools get fewer features.
  • No auto uploads. The README says ECC never uploads diagnostics on its own.
  • License: MIT. Free to use, change and even use in business. Just keep the copyright notice.

The bottom line

ECC turns a plain AI coding helper into a trained team member with a plan, a reviewer and a security guard. It is a big toolkit, so start with one workflow, like planning a feature. One guided command gets you going.
