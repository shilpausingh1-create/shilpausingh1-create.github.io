DeepSeek Harness: DeepSeek's own open-source AI agent you can shape

DeepSeek Harness is DeepSeek's free, open-source AI agent where every feature is a plugin you can swap, add or build yourself.

DevelopersBusinessStudents

stars: 250K · license: MIT · platforms: Any computer with Node.js (runs in your browser)

The problem it solves

AI agents are getting popular. An agent is an AI helper that does not just chat. It takes actions, like reading files, running commands and following a plan.

But most agents are a closed box. You get the features the company picked. If you want it to work a different way, or connect to a tool you use, you are usually stuck.

DeepSeek, the AI lab behind the DeepSeek models, took a different path. It released its own agent as open source, built so every part can be swapped out.

What it is

DeepSeek Harness, called "dsh" for short, is a free, open-source agent harness made by DeepSeek AI. A harness is the frame around an AI model. It gives the model tools, memory and a way to work on real tasks.

Its big idea is "everything is a plugin." A plugin is an add-on piece. In DeepSeek Harness, the features themselves are plugins. That means you can remove one, replace it, or write your own. Other people can share plugins too. The README asks plugin makers to tag their projects with "dsh-plugin" so others can find them.

It runs as a small program on your computer and gives you a web page in your browser to work from.

One important note up front. The README says DeepSeek Harness is in "developer preview" and changing fast. It warns, in capital letters, that there will be changes that break things.

Who it's for

  • Tinkerers who want an AI agent they can take apart and rebuild.
  • Developers who want to build their own plugins for an agent.
  • Researchers and students studying how AI agents work.
  • Tech-curious business teams who want to test what an agent could do on their own projects.
  • Anyone who follows DeepSeek and wants to try its official agent early.

Right now, this is best for people comfortable with some technical setup. It is an early preview, not a polished app.

What you can do with it

Based on the README and its user guide:

  • Run it in your browser. One command starts a web interface on your own computer.
  • Connect a model. Enter a DeepSeek API key in the settings. The guide says other providers and custom endpoints that work like OpenAI's are also supported.
  • Work on a folder. Pick a "workspace" (a project folder) for the agent to work in.
  • Give it tasks. The guide's example: ask it to summarize a project and list its main parts.
  • Let it act. The agent can read and edit files in your workspace, run commands, hand off smaller jobs, and keep a plan.
  • Approve risky steps. The web page asks you before actions that need approval under your permission settings.
  • Add or build plugins. Swap features in and out, or write your own.
  • Use other modes. The guide also mentions a Python toolkit and other command-line modes.

How to start, step by step

What you need first: Node.js (a free program that runs many developer tools, from nodejs.org), and a DeepSeek API key or another supported AI provider.

  1. Read the project's safety notice (SAFETY.md) first. The README asks you to.
  2. Install Node.js if you do not have it.
  3. Open Terminal (on a Mac) or your command window.
  4. Paste this and press Enter:
npx @deepseek-ai/dsh web
  1. A page opens in your browser. By default it lives at 127.0.0.1:3080, which is an address on your own computer.
  2. Go to Settings, then Models, and enter your DeepSeek API key.
  3. Click Choose workspace and pick a folder for it to work in.
  4. Start a session and give it a task.

Good to know

  • It is early and experimental. The safety notice says it has not had a security audit and should not be treated as secure or ready for serious use.
  • It can change your files. The agent can run AI-written code and commands. The safety notice warns that mistakes, bad input or untrusted plugins could delete files or leak data. Safety prompts help but are not a guarantee.
  • Play it safe. DeepSeek suggests running it with as little access as possible, ideally in a separate test setup like a virtual machine (a computer inside your computer). Keep backups. Review plugins and commands before you allow them.
  • The model may cost money. The harness is free, but using DeepSeek's models through an API key is a paid service. Check DeepSeek's website for current prices.
  • License, in plain words. It uses the MIT license. You can use, change and share it, even for work. It comes with no warranty, so you use it at your own risk.
  • Help is available through GitHub Discussions and a Discord community.

The bottom line

DeepSeek Harness is a rare look at a major AI lab's own agent, fully open for anyone to change. It is built for shaping, not just using. Just treat it like the early preview it is: try it on test projects, not your important files.

Get it: github.com/deepseek-ai/deepseek-harness
