RTK: a free way to shrink what your AI coding helper has to read

A small free tool that trims noisy command output before your AI coding assistant reads it, so it uses fewer tokens.

Developers

stars: 83K · license: Apache-2.0 + BUSL-1.1 · platforms: Mac, Windows, Linux

The problem it solves

AI coding assistants like Claude Code, Cursor or Copilot do a lot of work by running commands on your computer. Each command spits out text. The AI reads all of it.

The trouble is, much of that text is noise. A test run might list hundreds of passing tests just to tell you two failed. A file listing might print one line per file. Your AI reads every word anyway.

AI tools charge by "tokens" (small chunks of text the AI reads or writes). And they can only hold so much text in mind at once. So all that noise costs you money and crowds out the stuff that matters.

RTK cuts that noise before your AI ever sees it.

What it is

RTK is a small, free program that sits between your AI coding assistant and your computer's command line. When the AI runs a command, RTK steps in, cleans up the output, and hands back a short version.

The README says it can make command output up to 90% smaller. It is a single program, supports more than 100 commands, and adds under 10 milliseconds of delay. Once set up, your AI does not need to know RTK is there. It just gets cleaner answers.

Who it's for

  • Software developers who use AI coding assistants every day.
  • Teams watching their AI tool bills.
  • Anyone who hits the "too much text" limit in long AI coding sessions.

To be honest, this is a tool for people who code with AI. If you do not use a coding assistant in a terminal, you will not need it.

What you can do with it

From the README, RTK changes common outputs like this:

  • Test results: shows only failing tests and collapses passing ones into a count.
  • File lists: shows a tidy tree with file counts instead of one line per file.
  • Search results: cuts long lines and groups matches by file.
  • Git history and status: keeps just the key facts, like who changed what.
  • Docker lists: keeps only the essential fields.
  • Repeated log lines: squashes duplicates into one line with a count.

It also gives you:

  • Support for 18 AI coding tools, including Claude Code, GitHub Copilot, Cursor, Gemini CLI, Codex and Windsurf.
  • A savings dashboard: type rtk gain to see how much it has trimmed, with daily breakdowns and a simple graph.
  • A "missed savings" finder: rtk discover points out where it could help more.
  • An optional extra, RTK Proxy, that can also compress the traffic between your AI tool and the AI company.

How to start, step by step

What you need first: an AI coding assistant you already use, like Claude Code or Cursor, and access to your computer's Terminal.

  1. Install RTK. On a Mac or Linux computer with Homebrew (a free app installer):
brew install rtk

On Windows, use winget install rtk-ai.rtk.

  1. Check you got the right one, since another program with the same name exists. Type rtk gain. You should see a savings dashboard, not "command not found."
  2. Connect it to your AI tool. For Claude Code or Copilot, type:
rtk init -g

Other tools have their own version, like rtk init -g --agent cursor for Cursor.

  1. Restart your AI tool.
  2. Work as usual. When your AI runs a command like git status, RTK quietly rewrites it and returns the short version.

Good to know

  • Savings on output are not the same as savings on your bill. The README is upfront about this. RTK shrinks command output, but your bill also includes your own prompts, chat history and the AI's replies. So your total bill drops by less than the headline number.
  • Token counts are estimates. The percentages are reliable, but the exact token numbers are rough guesses.
  • It only catches shell commands. Some AI tools have built-in ways to read files that skip RTK.
  • Privacy: RTK collects no command content and no file contents. Usage stats are anonymous and off unless you turn them on.
  • Cost: free, including for work use.
  • License, in plain words: the main tool is Apache-2.0, which means free to use, change and even use in business, as long as you keep the notice. One built-in part (the "engine") and the optional proxy use a different license called BUSL-1.1. Using them is free, even at work. What is not allowed is selling RTK, or something built from it, as a product or service to others. If you want only the fully open part, there is a separate "rtk-oss" edition. Check the license files for details.

The bottom line

RTK is a quiet helper for people who code with AI. It strips out noise so your assistant reads less and focuses on what matters. Setup takes two commands, and the built-in dashboard shows you exactly what it saved.

Get it: github.com/rtk-ai/rtk
