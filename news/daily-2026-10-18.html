18 Oct 2026, 17:18 IST

DeepSeek

DeepSeek says free model update tops a coding test

17 Oct 2026, 19:17 IST

What happened

DeepSeek has released an update to its model called V4.1-Flash-1017. The weights are open, and by DeepSeek's own table it scores 77.0 on a coding test, ahead of a model listed as Opus 5 on that one test. Our take: it is one test, so treat it as a hint, not a verdict.

Corrected 19 Oct: The sources never name Claude; 'chases Claude' was our inference from the Hugging Face page, which lists Opus 5 at 74.0 vs DeepSeek's 77.0 on DeepSWE (DeepSeek's own table). Headline changed 19 Oct to a neutral, sourced one (77.0 on DeepSWE in DeepSeek's own table, vs Opus 5 74.0). All corrections

DeepSeek

DeepSeek opens search API at $0.75 per 1,000

17 Oct 2026, 14:23 IST

What happened

DeepSeek has opened two web tools to any developer: a Search API and a Fetch API. Each costs $0.75 for every 1,000 successful calls. Some uses are free for now, and billing starts on 1 November 2026, Beijing time. This gives AI apps a cheap way to look things up on the web.

Corrected 19 Oct: Search and Fetch both cost $0.75 per 1,000 successful calls. Only server-side calls via DeepSeek Harness, Claude Code or Codex are free until 1 Nov 00:00 Beijing time. All corrections
